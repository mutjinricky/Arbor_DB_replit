## Matching Rule

기존 위치 데이터의 수목 ID 뒤 숫자와 엑셀의 `웨이` 번호를 숫자로 변환해 매칭한다.

예시:

| 위치 마커 ID | 숫자 변환 | 엑셀 `웨이` | 연결 결과 |
| --- | ---: | ---: | --- |
| `P001` | `1` | `1.0` | `P001`에 엑셀 1번 행 데이터 연결 |
| `P002` | `2` | `2.0` | `P002`에 엑셀 2번 행 데이터 연결 |
| `P507` | `507` | `507.0` | `P507`에 엑셀 507번 행 데이터 연결 |

마커 ID는 화면과 데이터 연결 기준으로 계속 `P001` 같은 기존 형식을 유지한다. 엑셀의 `웨이` 값은 표시용 기본 ID로 바꾸지 않고, 기존 위치 데이터와 연결하기 위한 매칭 키로만 사용한다.

## Implementation Plan

추후 구현 시 아래 순서로 적용한다.

1. `황산공원.xlsx`를 읽어 `웨이`, `직경`, `수고` 데이터를 추출한다.
2. `웨이` 값을 정수로 변환한다.
3. 기존 위치 마커 ID의 숫자 부분을 정수로 변환한다.
4. `P001`의 숫자 `1`과 엑셀 `웨이` `1`을 매칭한다.
5. 매칭된 위치 데이터에 `diameter`, `height` 값을 추가한다.
6. 사진 데이터는 아직 없으므로 기존처럼 빈 상태 또는 `사진 없음` 상태를 유지한다.
7. 수목지도에서 `황산공원 예찰` 사업을 선택하면 기존 507개 마커를 그대로 표시하되, 마커 클릭 시 새로 연결된 수고와 흉고직경도 함께 표시한다.

## Validation Rules

- 위치 데이터는 507개여야 한다.
- 엑셀 데이터도 507개여야 한다.
- `P001` ~ `P507`이 모두 엑셀 `웨이` `1` ~ `507`과 1:1로 연결되어야 한다.
- 중복된 `웨이` 번호가 있으면 구현 전에 오류로 보고한다.
- 위치 데이터에는 있지만 엑셀에 없는 번호가 있으면 해당 마커는 유지하고 `수고`, `흉고직경`은 `데이터 없음`으로 표시한다.
- 엑셀에는 있지만 위치 데이터에 없는 번호가 있으면 지도에 새 마커를 만들지 않고 검증 결과에만 표시한다.
- `직경`, `수고`가 비어 있는 행은 임의값을 넣지 않고 빈 값으로 유지한다.

## UI Behavior

- 수목지도 페이지의 기존 `사업목록` 버튼과 팝업은 유지한다.
- `황산공원 예찰`을 선택하면 현재처럼 황산공원 위치의 507개 마커가 표시된다.
- 마커 클릭 시 기존 세부 수목정보 팝업 UI를 재사용한다.
- 세부 수목정보에는 기존 위치 정보에 더해 엑셀에서 연결된 `수고`, `흉고직경`을 표시한다.
- 사진, 해충피해 사진 등은 아직 받은 데이터가 없으므로 표시하지 않는다.
- 다른 사업이나 전체 사업 화면의 기존 동작은 변경하지 않는다.
