# 황산공원 예찰 위치데이터 마커 등록

## 목적

`default(경위도-도분초).csv`의 수목별 위치 데이터를 `황산공원 예찰` 사업(`BH-2024-004`)에 연결해 수목지도에서 마커로 표시한다.

현재 단계에서는 위치 데이터만 등록한다. 수목 사진, 수고, 흉고직경, 수목 상태 데이터는 추후 같은 수목 ID로 추가 병합한다.

## 원본 데이터

- 원본 파일: `C:\Users\shyun\Downloads\default(경위도-도분초).csv`
- 총 위치 수: 507개
- 수목 ID: CSV의 `이름` 컬럼 사용 (`P001` ~ `P507`)
- 좌표 원본: 도분초(DMS)
- 변환 좌표: 십진수 경위도
- 보존 메타데이터:
  - 고도
  - UTC시각
  - 로컬시각

## 변환 결과

- JSON 경로: `public/data/project_maps/hwangsan-park-observation.json`
- 연결 사업 ID: `BH-2024-004`
- 중심 좌표:
  - 위도: `35.3003594054`
  - 경도: `128.99418599`
  - 기본 줌: `16`
- 좌표 범위:
  - 경도: `128.9789600278` ~ `129.0096355833`
  - 위도: `35.2887682222` ~ `35.3102324444`
  - 고도: `28.382m` ~ `54.683m`

## 적용 방식

- `projectMapData.ts`에는 대량 좌표를 직접 넣지 않는다.
- `BH-2024-004`는 `/data/project_maps/hwangsan-park-observation.json`을 비동기로 로드한다.
- 수목지도에서 `사업목록 > 황산공원 예찰`을 누르면 해당 JSON을 불러와 507개 마커를 표시한다.
- 마커 기본 수종은 `미지정 수목`으로 둔다.
- 수고, 흉고직경, 사진은 현재 데이터가 없으므로 임의값을 넣지 않는다.

## 상세 팝업 표시

황산공원 위치 마커를 클릭하면 기존 수목 상세 팝업을 재사용한다.

현재 표시 항목:

- 수목 ID
- GPS 좌표
- 고도
- 관측시각
- 수종: `미지정 수목`

데이터가 아직 없는 항목:

- 수고: `데이터 없음`
- 흉고직경: `데이터 없음`
- 수목사진 및 현장 피해 사진: `사진 없음`

## 추후 병합 기준

나중에 수목 사진이나 상세 데이터를 추가할 때는 CSV의 `이름` 컬럼 값(`P001`, `P002` 등)을 기준으로 병합한다.

추가 예정 데이터 예:

- 수목사진
- 수목해충피해 사진
- 가지치기 미흡 사진
- 뿌리 융기 사진
- 부후/고사지 사진
- 수고
- 흉고직경
- 수종
- 상태/피해 메모

## 검증 항목

- `황산공원 예찰`이 수목지도 사업목록 팝업에 표시되는지 확인한다.
- `황산공원 예찰` 선택 시 지도가 황산공원 중심 좌표로 이동하는지 확인한다.
- 507개 위치 마커가 표시되는지 확인한다.
- `P001`, `P507` 마커가 누락되지 않는지 확인한다.
- 마커 클릭 시 GPS, 고도, 관측시각이 표시되는지 확인한다.
- 사진/수고/흉고직경이 없는 항목은 임의값 대신 빈 상태로 표시되는지 확인한다.
- `전체 사업` 선택 시 기존 전체 수목지도 상태로 돌아오는지 확인한다.
