# 수목지도 사업목록 임시 매핑 기능

## 목표

수목지도 페이지 상단의 `지도 보기` 버튼 바로 왼쪽에 `사업목록` 버튼을 추가한다.

버튼을 누르면 사업이력페이지에 있는 사업명이 팝업으로 표시된다. 기존 사업이력/프로젝트/대시보드/수목관리 하위 페이지는 그대로 두고, 수목지도 화면에서만 사업별 임시 매핑 데이터를 볼 수 있게 한다.

## 동작 기준

- 수목지도 최초 진입 시에는 기존 전체 수목지도와 마커를 그대로 표시한다.
- `사업목록` 팝업에는 사업명만 표시한다.
- `전체 사업`을 누르면 기존 전체 수목지도로 돌아간다.
- 매핑 데이터가 없는 사업을 누르면 수목지도 위치와 마커는 바뀌지 않는다.
- 매핑 데이터가 있는 사업을 누르면 수목지도만 해당 사업 기준으로 바뀐다.
  - 지도 중심이 해당 사업지로 이동한다.
  - 해당 사업의 매핑 수목 마커만 표시한다.
  - 마커를 누르면 해당 사업 수목의 세부정보 팝업을 연다.

## 데이터 구조

사업별 지도 데이터는 사업이력 데이터와 분리해서 관리한다.

- 기준 키: 사업 `id`
- 저장 키: `dryad_project_map_data_v1`
- 기본 구조:

```ts
{
  [projectId]: {
    projectId: string;
    center?: { lat: number; lng: number; zoom?: number };
    trees: Array<{
      id: string;
      lat: number;
      lng: number;
      height: number;
      diameter: number;
      species: string;
      district?: string;
      photoUrl?: string;
      photos?: Array<{ label: string; url: string }>;
    }>;
  }
}
```

현재 구현에는 예시 확인용으로 `BH-2023-001` 사업의 임시 매핑 데이터가 포함되어 있다. 이후 사용자가 사업과 매핑 데이터를 추가하면 같은 구조로 확장한다.

## 세부 수목정보

사업 매핑 마커를 클릭하면 기존 수목 상세 팝업 UI를 재사용한다.

표시 대상:

- GPS 좌표
- 수고
- 흉고직경
- 수종
- 점검일
- 수목사진
- 현장 피해 사진

사진 탭은 기존 4칸을 사용한다.

권장 사진 라벨:

- 가지치기 미흡
- 해충피해
- 뿌리 융기
- 부후/고사지

사진이 일부만 있으면 있는 사진만 표시하고 나머지는 `사진 없음` 상태로 둔다.

## 검증 항목

- 수목지도 최초 진입 시 기존 전체 수목지도와 마커가 보이는지 확인한다.
- `사업목록` 버튼 클릭 시 사업명만 있는 팝업이 열리는지 확인한다.
- 매핑 데이터가 없는 사업 클릭 시 지도와 마커가 바뀌지 않는지 확인한다.
- 매핑 데이터가 있는 사업 클릭 시 지도 위치가 이동하고 해당 사업 마커만 보이는지 확인한다.
- 사업 마커 클릭 시 GPS, 수고, 흉고직경, 사진 탭의 최대 4장 사진이 보이는지 확인한다.
- `전체 사업` 클릭 시 기존 전체 수목지도 상태로 돌아오는지 확인한다.
- 기존 지도 보기/목록 보기, 검색, 필터, 마커 클릭/호버 기능이 유지되는지 확인한다.
